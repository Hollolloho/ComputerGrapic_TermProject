# AEGIS 코어실과 필수 모델

모델 단위는 미터이며 +Y 축이 위쪽이다. 드론, 보스, 소품의 정면은 +Z다. 진입실부터 코어실까지의 진행 방향은 −Z다.

| 파일 | 내용 |
|---|---|
| `runtime/obj/core_room.obj`, `runtime/obj/core_room.mtl` | 코어실 형상과 재질. 재질별 메시로 묶었다. |
| `runtime/placement.json` | 시험 복도 접합 기준, 보스·엄폐물·보급대 배치, 충돌용 상자. |
| `../entry_room/runtime/placement.json` | 안전 진입실과 시험 복도 입구 접합, 플레이어 시작점, 분석 단말 배치. |
| `../props/runtime/assembly.json` | 분석 단말, CW-01C 무기 보급대, 수정탄, 수정 파편 3종의 OBJ와 치수·앵커. |

## 배치 기준

시험 복도의 기준은 `4bc595d:asset/corridor/test_scene/scene_manifest.json`이다. 진입실은 복도 입구와 같은 원점을 쓴다. 코어실 입구를 복도 기준 `(0, 0, -18.2)`에 두면 바닥 Y=0이 맞고, 코어실 문턱이 복도 마지막 타일 앞의 틈을 채운다. 복도 쪽의 기존 분리 문틀과 문짝을 이음부에 사용한다. 코어실의 입구 개구 폭과 높이는 각각 6.19m, 3.392m다. 엄폐물 두 곳의 형상은 같은 시험 복도의 `cover_cabinet.obj`를 사용한다. 시험 복도 모델과 문·엄폐물은 T006 작업에서 가져온다.

보스 E는 `8834765`의 원본 패키지를 사용한다. 코어실 로컬 `(0, 5.8, -8.8)`에 천장 부착 원점을 놓으면, 부품을 조립한 본체의 최저점이 바닥에서 약 2.126m다. 장갑은 ±X 방향으로 각각 0.555m 이동한다. 양쪽 포탑의 좌우 회전은 +Y 축 −25°~25°, 상하 회전은 +X 축 −10°~35°다. 보스의 노드 부모 관계, 텍스처와 코어 활성 조건은 기존 `../boss_e/runtime/assembly.json`을 따른다.

보급대는 오른쪽 엄폐물의 입구 쪽에 놓인다. 보급대의 무기 앵커에 `../cw01c/runtime/assembly.json`의 부품별 조립 이동을 합성하면 거치 모습을 재현할 수 있다. 진입실 분석 단말은 +Y 축 90° 회전으로 통로를 향한다. 상호작용 위치는 소품 앵커를 배치 변환한 점을 쓴다.

## 검증 범위

Blender에서 보스 14개 부품과 원본 아틀라스 5종을 조립했다. 장갑 이동 전후, 포탑 각도 범위, 천장 접점, 바닥과의 여유를 기하 검사했다. 정면 +Z측에서 코어를 향한 평행 광선 표본 1,103개는 장갑을 닫으면 전부 가려지고, 장갑을 완전히 열면 모두 노출됐다. 게임에서 사용할 시야 판정과 충돌은 장면 연결 후 검증한다.

독립 고정 포탑은 기존 승인 초안 패키지를 확보한 뒤 분리 부품과 피벗을 확인한다.
