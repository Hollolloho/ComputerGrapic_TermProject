# 06. 기본 완료 뒤 선택 확장

아래만 선택 항목이다. 카메라 5가지·잔향·안개·추론은 선택 확장이 아니다. 기본 목표를 다 끝내기 전 시작하지 않는다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| 상태 | ID | 담당 | 선행 | 한 번에 할 변경 | 완료 확인 |
|---|---|---|---|---|---|
| [ ] | X001 | A | Q015 | FMOD 실제 버전·연결 조건 확인 | 필요 런타임과 이용 조건 기록 |
| [ ] | X002 | A | X001 | FMOD 초기화와 종료만 연결 | 실패 로그와 정상 종료 확인 |
| [ ] | X003 | B | X002 | 사용 가능한 효과음 파일 하나 준비 | 출처와 이용 조건 기록 |
| [ ] | X004 | A | X003 | 조사 성공에 효과음 한 번 연결 | 반복 재생 없이 재생 |
| [ ] | X005 | A | X004 | 음소거 연결 | 꺼도 퍼즐을 풀 수 있음 |
| [ ] | X006 | 공동 | Q015 | Assimp·OBJ 하나의 도입 필요성 결정 | 필요 없다면 미사용으로 표시 |
| [ ] | X007 | A | X006 | 필요한 경우 모델 읽기·단색 표시 | 스케일·축·법선 확인. 별도 하위 항목으로 나눔 |
| [ ] | X008 | 공동 | X007 | 장식 물체 하나만 교체해 확인 | 시야·충돌·정답 변화 없음 |
| [ ] | X009 | 공동 | Q015 | B안의 과거 기록 조작 증거와 현재 살인 시간표 설계 | 접수소 단서·조작자 연결·R01 시점·현장 연결·다른 용의자 배제를 검토. 방문·동기만으로 유죄를 정하지 않음 |
| [ ] | X010 | 공동 | X009 | 남은 시간으로 사건 확장 여부 결정 | 상세 범행·증거·결말과 새 범위를 사용자 검토 후 문서에 반영하고 구현. 무리하면 다음 제작으로 이월 |

모든 선택 항목은 미사용/다음 제작으로 남길 수 있다. FMOD를 사용할 사운드는 FMOD로, 외부 모델 로더는 Assimp로 한다. 버전·허가를 이 문서에서 검증했다고 주장하지 않는다.
