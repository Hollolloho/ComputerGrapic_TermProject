# 00. 실행·큐브·한글

첫 문서다. 제품 코드가 아직 구현되지 않은 상태에서 시작한다. [최소 구조](../05_TECHNICAL_STRUCTURE.md)를 참고한다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| 상태 | ID | 담당 | 선행 | 한 번에 할 변경 | 완료 확인 |
|---|---|---|---|---|---|
| [ ] | B001 | 공동 | 없음 | A PC에서 기존 실습 실행 | 실행 성공 또는 실제 오류 메시지 기록 |
| [ ] | B002 | 공동 | B001 | B PC에서 같은 실습 실행 | 두 PC의 실행 화면 확인 |
| [ ] | B003 | A | B002 | 변경 전 실습 기준 버전 보존 | 복구할 파일 또는 버전이 있음 |
| [ ] | B004 | A | B003 | 게임 main 하나를 x64 Debug에 등록 | 실습 main 중복 없이 빈 게임 창 실행 |

| [ ] | B007 | A | B006 | 셰이더 로딩 실패에 파일 경로 로그 추가 | 잘못된 경로 테스트 후 정상 파일 복구 |
| [ ] | B008 | A | B007 | 공유할 큐브 정점·인덱스 한 세트 표시 | 단색 큐브 한 개 |

| [ ] | B014 | B | B013 | 실행 방법과 폰트 출처 기록 | 상대가 파일만 보고 실행 위치·출처 확인 |
