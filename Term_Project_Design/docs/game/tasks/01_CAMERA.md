# 01. 이동·자전·부모·확대

CAM_MOVE, CAM_SELF, CAM_PARENT, CAM_ZOOM의 기초를 구현한다. 공전은 다음 문서에서 필수로 이어진다. [카메라 명세](../02_REQUIRED_CAMERA.md)를 함께 연다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| 상태 | ID | 담당 | 선행 | 한 번에 할 변경 | 완료 확인 |
|---|---|---|---|---|---|
| [ ] | C001 | A | B009 | 고정 View·Projection으로 큐브 보기 | 멀수록 작게 보임 |
| [ ] | C002 | A | C001 | 창 크기에 맞춰 투영 비율 변경 | 큐브가 찌그러지지 않음. 높이0은 계산 생략 |
| [ ] | C003 | A | C002 | 프레임 경과 시간 변수 추가 | 개발 로그의 시간이 갱신 |
| [ ] | C004 | A | C003 | playerPosition을 한 곳에 보관 | 초기 위치가 반복 실행에서 동일 |
| [ ] | C005 | A | C004 | 눈높이를 로컬 값으로 분리 | 부모 위치와 눈높이 데이터가 별개 |
| [ ] | C006 | A | C005 | 부모×로컬로 EyeWorld 계산 | 부모 X 이동 시 눈 카메라도 같은 X 이동 |
| [ ] | C007 | A | C006 | EyeWorld 역행렬을 View로 사용 | 화면과 카메라 좌표의 이동 방향이 맞음 |
| [ ] | C008 | A | C007 | W 전진만 적용 | 경과 시간 기준으로 전진 |
| [ ] | C009 | A | C008 | S 후진 추가 | 전진한 자리로 돌아옴 |
| [ ] | C010 | A | C009 | A·D 옆 이동 추가 | 수평 이동만 함 |
| [ ] | C011 | A | C010 | 대각선 이동 정규화 | W+D가 W보다 빠르지 않음 |
| [ ] | C012 | A | C011 | 부모 yaw를 마우스 좌우에 연결 | 눈 위치 고정, 방향만 변화 |
| [ ] | C013 | A | C012 | 눈 카메라 pitch와 각도 제한 연결 | 위아래를 보되 뒤집히지 않음 |
| [ ] | C014 | A | C013 | W 이동 방향을 부모 yaw에 맞추기 | 위를 보며 W를 눌러도 날지 않음 |
| [ ] | C015 | A | C014 | 포커스 복귀 후 마우스 기준 초기화 | 다른 창 복귀 시 시점이 튀지 않음 |
| [ ] | C016 | A | C015 | 기본 FOV를 별도 변수로 보관 | 방향·위치와 투영 값이 분리됨 |
| [ ] | C017 | A | C016 | 개발키로 FOV만 줄이기 | 위치 불변, 큐브만 크게 보임. 다시 기본값으로 복구 |
| [ ] | C018 | 공동 | C017, B012 | 부모 위치·눈높이·FOV·방향 표시 | 이동/자전/부모/확대의 차이를 수치와 화면으로 확인 |

이 네 기능은 선택 사항이 아니다. 부모 구조를 나중에 덧붙이기보다 처음부터 작은 행렬 조합으로 만든다. 아직 방 충돌은 다음 단계에서 붙인다.
