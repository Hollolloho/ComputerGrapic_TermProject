# 05. 필수 검증·제출

핵심 구현을 마친 다음 수행한다. 문서 작성만으로 아래 체크를 완료하지 않는다. [검증 명세](../07_ACCEPTANCE.md)에 따른다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| 상태 | ID | 담당 | 선행 | 한 번에 할 변경 | 완료 확인 |
|---|---|---|---|---|---|
| [ ] | Q001 | 공동 | E026 | 5가지 기능을 하나씩 실제 실행 | FOV/위치/방향/공전중심/부모 변환 확인 |
| [ ] | Q002 | B | Q001 | 상세보기 10회 열고 닫기 | 탐색 위치·FOV·입력 복원 |
| [ ] | Q003 | B | Q002 | 잔향 왕복10회 확인 | 현재 위치·방향·충돌·안개가 유지 |
| [ ] | Q004 | B | Q003 | R연타·전환중Tab/Esc 확인 | 상태 중복과 진행 막힘 없음 |
| [ ] | Q005 | B | Q004 | 최소화·포커스 복귀·창 크기 변경 확인 | 이동점프·문자잘림·시야왜곡 없음 |
| [ ] | Q006 | A | Q005 | 판정 함수의 정답/오답/근거부족 검사 남기기 | 작은 실행 검사에서 세 경우 기대 결과 확인 |
| [ ] | Q007 | B | Q006 | 증거 수집 순서를 바꿔 플레이 | 모든 순서에서 재조사·정답 접근 가능 |
| [ ] | Q008 | 공동 | Q007 | 외부 플레이어 한 명 테스트 | 막힌 위치·이해한 근거·플레이 시간 기록 |
| [ ] | Q009 | 공동 | Q008 | 가장 큰 실패 하나 수정 | 동일 재현에서 문제가 해결. 여러 개면 하위 ID로 분리 |
| [ ] | Q010 | A | Q009 | Release x64 빌드 생성 | 기능과 에셋이 Debug와 동일 |
| [ ] | Q011 | A | Q010 | 별도 제출 폴더에 실행파일·필수에셋 구성 | IDE 밖에서 실행 |
| [ ] | Q012 | 공동 | Q011 | B PC에서 제출폴더만 실행 | 개인 경로 없이 처음부터 결과까지 |
| [ ] | Q013 | B | Q012 | 조작법·출처·실제 제한 작성 | 최종 포함 파일과 일치 |
| [ ] | Q014 | 공동 | Q013 | 2~3분 시연 연습 | 5가지와 잔향 추리 연관을 설명 |
| [ ] | Q015 | 공동 | Q014 | 최종 빌드 전체 진행 한번 확인 | 시작·조사·과거·결과·재시작 가능 |

해결하지 못한 오류는 지워진 체크가 아니라 알려진 제한으로 남긴다. 성공적인 컴파일만으로 그래픽·입력이 검증됐다고 보고하지 않는다.
