# 03. 방·조사·대화·수첩

실제 콘텐츠는 [첫 조사 과제](../03_STORY_AND_PUZZLE.md)를 기준으로 한다. 전체 살인 사건 설계는 선택 확장으로 분리했다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

소스와 UI 엔진을 늘리는 대신 고정 대사·증거 4개를 입력한다. 다른 인물 모형·맵·살인 연출은 아직 추가하지 않는다.
