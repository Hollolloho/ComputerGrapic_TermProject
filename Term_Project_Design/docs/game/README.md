## 이번 이야기 변경과 적용 범위

여관 주인은 마리다. 잔향은 과거 지원 기록을 검증하는 증거이며, 살인 동기는 에드윈의 은폐와 배신에 대한 보복이다. 잔향 의존·봉쇄 저지·조각 회수를 마리의 동기로 사용하지 않는다. 옛 접수소 조사와 최종 결말은 전체 사건 확장에 속한다. 기본 제출본은 방 하나·잔향 하나·NPC 두 명·카드 네 개의 목격 검증 과제를 유지한다.
