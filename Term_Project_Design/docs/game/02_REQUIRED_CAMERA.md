# 필수 카메라 5가지 명세

다섯 항목은 모두 제출 조건이다. 카메라와 관련한 사용자 정의를 기준으로 한다.

| 요구 ID | 기능 | 게임에서 쓰는 곳 | 합격 판정 |
|---|---|---|---|
| CAM_ZOOM | 확대 | 단서 상세보기의 휠 확대, 잔향 진입의 흡입감 | 위치 고정 상태에서 FOV가 줄고 대상이 크게 보임. 복귀 시 원래 값 |
| CAM_MOVE | 이동 | WASD 탐색·목격 위치로 가기 | 카메라 월드 위치가 변하고 충돌을 지킴 |
| CAM_SELF | 자전 | 1인칭 마우스 둘러보기 | 위치 고정, 방향만 변함 |
| CAM_ORBIT | 공전 | 잔향 조각 상세보기 | 대상 위치 고정, 카메라가 중심 주변을 일정 거리로 움직임 |
| CAM_PARENT | 부모 | PlayerRoot 아래 EyeCamera, InspectionPivot 아래 InspectCamera | 부모 월드 변환과 카메라 로컬 변환을 합쳐 위치·방향을 계산 |

## 최소 구조

```text
PlayerRoot — 수평 위치와 yaw
└─ EyeCamera — 눈높이와 pitch

InspectionPivot — 단서 중심과 공전 각도
└─ InspectCamera — 중심에서 떨어진 로컬 거리
```

플레이어에는 수평 이동과 yaw를, 눈 카메라에는 로컬 눈높이와 pitch를 둔다. 눈높이 외 로컬 X/Z 이동은 첫 버전에서 0이다. 마우스 자전은 눈 위치를 바꾸지 않는다. W 이동은 pitch가 아니라 몸의 수평 방향을 따른다.

열벡터 관례의 개념식:

```text
EyeWorld = Translate(playerPosition) * RotateY(yaw) * Translate(0, eyeHeight, 0) * RotateX(pitch)
View = inverse(EyeWorld)

InspectWorld = Translate(pivot) * RotateY(orbitYaw) * RotateX(orbitPitch) * Translate(0, 0, radius)
InspectView = inverse(InspectWorld)
```

카메라는 기본 -Z를 바라보는 정의로 통일한다. 부모에 스케일은 넣지 않는다. 부모 관계를 구현하기 위해 범용 장면 그래프·상속 계층은 필요 없다. 위 두 행렬 조합과 명확한 로컬/월드 데이터면 충분하다.

## 상세보기로 필수 기능을 단순하게 묶기

획득 조각의 표시용 복사본을 독립된 배경에 둔다. 원본 세계의 물체는 이동시키지 않는다. 상세보기 동안 기존 탐색 렌더링과 입력을 멈추고 별도 카메라로 그린다. 복잡한 화면 속 화면이나 프레임버퍼는 필요 없다.

- 왼쪽 버튼 드래그: 수평·제한된 수직 공전.
- 휠: FOV 확대/축소. radius는 고정해 확대와 공전의 차이를 보여준다.
- Esc: 상세보기 닫기. 열기 전의 카메라·월드 모드·커서 모드 복원.
- 뒷면 표식: 공전으로 확인할 수 있는 간단한 3D 돌출 도형 또는 큰 색상 표식.
- 확대 초기 제한값 예시: 35~70도. 공전 pitch는 약 -60~60도. 수치는 실행 후 조정한다.

확대는 카메라 투영 변경이며 카메라 전진이나 모델 스케일과 다르다. 과거 방 자체를 자유 공전시키지 않는다. 목격 위치의 시야를 검증하는 게임에서 벽 뒤를 보게 되면 단서 의미가 달라진다.

## 저장과 복원

EyeCamera의 최종 월드 행렬만 저장하지 말고 playerPosition·yaw·pitch·기본 FOV를 함께 저장한다. 상세보기용 orbitYaw·orbitPitch·FOV는 별도로 둔다. 상세보기 입력이 탐색 카메라를 바꾸지 않게 한다.

확대된 상세보기에서 나와도 잔향 전환 기준 FOV가 바뀌지 않는다. 효과를 줄인 잔향 옵션에서도 휠 확대는 남아 있으므로 CAM_ZOOM을 시연할 수 있다.

## 발표 확인

개발 표시로 모드·위치·yaw/pitch·FOV·radius·로컬 눈높이를 보여준다. 부모를 조금 옮겨 카메라가 같은 만큼 따라가는 모습과, 공전 중심의 옆면·뒷면을 보는 모습을 실제 실행한다. 수업 평가에 합격했다고 미리 단정하지 않는다.
