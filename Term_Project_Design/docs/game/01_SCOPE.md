# 현실적인 구현 목표

## 시간 예산

각자 하루 2~3시간, 주 5일을 가정한다. 2주면 각자 20~30시간, 합계 40~60시간이다. 3주면 각자 30~45시간, 합계 60~90시간이다. 합계 시간을 A의 그래픽 구현 시간으로 전부 쓸 수는 없다.

기준 계획은 **3주**다. 2주 고정이라면 넓은 마을이나 살인 사건 전체보다 기술 필수 항목과 작은 조사 과제를 우선한다. 시간은 보장이 아니라 배분 기준이고 첫 주 결과로 다시 계산한다.

## 반드시 완성할 기본 제출본

| 항목 | 상한 |
|---|---|
| 진행 길이 | 첫 플레이 약 3~5분의 조사 과제. 테스트로 측정 |
| 공간 | 작은 기록실 1개 + 창밖 목격 위치가 있는 짧은 통로 |
| 현재/과거 | 동일 공간의 물체 배치 2개, 잔향 1개 |
| NPC | 이보·마리 2명, 각 핵심 대사 2~3개 |
| 과거 인물 | 정지 모형 1개. 걷기·표정 없음 |
| 관찰 물건 | 잔향 조각 1개, 작업 기록 1개 |
| 증거 카드 | 4개, 고정 목록 |
| 상세보기 | 조각 1개. 카메라 공전·휠 확대, 뒷면 식별 표식 |
| 추론 | 주장 1개와 근거 선택, 오답 재시도, 조사 결과 화면 |
| 연출 | 가장자리 안개, 진입 중 FOV 변화, 안전한 복귀 |
| 입력 | WASD, 마우스, E, R, Tab, 숫자키, Enter, Esc |
| 제출 | Release 실행 파일, 에셋, 조작법과 시연 자료 |

**확대·이동·자전·공전·부모 전부 기본 제출본에 포함한다.** 필수 기능을 빼서 일정을 맞추지 않는다.

첫 완료 화면은 “그 위치의 사건 당일 목격 증언은 신뢰할 수 없다”는 조사 결과다. 현재 시제품은 마리의 유죄까지 입증하는 완성된 살인 사건이 아니다. 게임의 최종 비전은 살인 수사이며 이 과제는 그 첫 조사 구간을 플레이 가능하게 만드는 목표다.

## 3주 안에 기본 제출본이 먼저 안정되면

- FMOD 효과음 1개와 음소거를 추가한다. 사운드 도구는 사용자의 지정대로 FMOD다.
- 문서·대사 한두 개로 마리가 오래 자책한 사정과 에드윈을 믿었던 관계를 보강한다. 리아의 상세 대화와 결말은 전체 사건 확장에 둔다.
- 반드시 범인 특정 근거가 완성된 경우에만 최종 지목으로 확장한다. 옛 접수소 잔향·구호 기록 조사·기록 정정과 살인 책임을 다루는 결말은 이 확장에 속한다. 새로운 NPC·맵이 필요한 경우 다음 제작으로 넘긴다.

Assimp는 외부 OBJ를 도입할 때 사용한다. 외부 모델을 쓰지 않는 기본 도형 버전도 정상적인 제출본이다. 필요 없는 로더를 먼저 만들지 않는다.

## 완료 기준과 금지되는 축소

다섯 카메라 기능을 각각 실행할 수 있고, 잔향에서 직접 시야를 확인해 증거를 제출하며, 결과 화면과 재시작까지 진행된다. 중앙 시야·한글·복귀 위치·충돌·단서 논리는 줄이지 않는다.

저장/불러오기, 전투, NPC 이동, 과거 변경, 실시간 시간 흐름, 음성 연기, 넓은 마을, 임의 기억 삭제, 자연어 정답 판정은 다음 범위로 둔다.
