# 첫 구현 과제 — 시야 검증용 초안

이 문서의 상대 날짜와 레온의 목격 진술은 기능 검증용 제안이다. STORY의 실제 범행 시간표와 잔향 장면을 확정한 것이 아니다. 전체 사건에 편입할 때 실제 방문 순서와 맞춘다. 레온의 기억 착오·고의적인 거짓말·살인 시도를 이 과제만으로 확정하지 않는다.

## 공간과 진술

여관 기록실과 북쪽 창밖 목격 지점을 같은 좌표로 현재/과거에 둔다. 현재 책장은 옆에 있고 과거 책장은 창 앞에서 책상을 가린다. 레온의 테스트 진술은 “그날 저녁, 북쪽 창밖 표시 지점에서 에드윈이 책상 앞에 앉아 있는 것을 봤습니다”다.

검증용 작업 기록은 “그날 낮 설치, 다음 날 아침 철거, 중간 이동 없음”이라고 적는다. 실제 게임에 사용할 때는 '그날'을 전체 시간표의 명확한 사건 날짜와 연결해야 한다. 장면 한 순간의 가림이 저녁 전체에 유지됐다는 점은 기록으로 뒷받침한다.

마리의 안내 대사는 “그 돌의 뒷면 표식을 보세요. 어느 방의 장면인지 기록과 맞춰볼 수 있어요”다. 의뢰인·조력자로서 관찰 방법을 안내하며 카일의 범행이나 미정인 다른 인물의 비밀을 공개하지 않는다.

## 고정 카드 4개

| ID | 사실인 정보 | 획득 |
|---|---|---|
| EV_TESTIMONY | 레온이 위와 같이 주장했다 | 대화 |
| EV_SHARD | 조각 뒷면 표식과 설명판이 기록실 장면을 연결한다 | 공전 상세보기에서 E |
| EV_WORKLOG | 해당 기간의 책장 설치·철거·유지 기록 | 기록 물체 E |
| EV_OCCLUSION | 잔향의 지정 위치에서 책장 때문에 책상 앞을 볼 수 없다 | 잔향 위치 도달 후 E |

주장 A: 그날 저녁 그 위치에서 책상 앞을 볼 수 있었다. 오답.

주장 B: 해당 위치·시각의 목격이라는 주장은 신뢰하기 어렵다. 정답.

주장 C: 레온이 에드윈을 죽였다. 근거 부족.

정답에는 EV_TESTIMONY·EV_WORKLOG·EV_OCCLUSION이 필요하고 장소 확인 카드 EV_SHARD도 과제 완료 조건으로 요구한다. 선택 순서는 상관없다. 조각을 발견했다고 자동 정답 처리하지 않는다.

결과는 “목격 주장의 위치 또는 시점을 다시 확인해야 한다”다. 레온의 착오인지 고의인지, 에드윈의 사망 시각이 언제인지는 아직 확정하지 않는다. 정지 모형만으로 생존도 확정하지 않는다. 이 과제만으로 카일의 살인을 입증하거나 레온의 시도 제안을 사실로 만들지 않는다.

구현 전에 채택 여부와 좌표·대사를 확인하고, 공간의 가림이 실제 화면에서 맞는지 테스트한다.
