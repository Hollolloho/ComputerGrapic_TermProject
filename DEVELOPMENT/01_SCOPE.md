# 구현 범위

## 유지하는 개발 조건

2명, 각자 하루 2~3시간. OpenGL 확대·이동·자전·공전·부모 관계는 모두 필수다. 2~3주 계획은 실제 개발을 시작하는 날부터 계산하고 과거 날짜부터 완료한 것으로 보지 않는다.

3주·주5일이면 각자 30~45시간이며 학습·통합·오류 대응 시간도 이 안에 포함된다. 두 사람 모두 OpenGL 초보로 시작한 기존 가정은 현재 숙련도를 다시 확인해 조정한다. 이를 이유로 패턴 엔진부터 만들지 않는다.

## 전체 게임과 기본 제출본

전체 게임은 마리·레온·카일·노아의 비밀과 에드윈 살인, 7년 전 화재를 푸는 머더미스터리다. 기본 제출본은 그 게임의 작은 조사 구간을 시연한다.

| 항목 | 기본 시제품 상한 |
|---|---|
| 공간 | 여관 기록실 1개와 짧은 통로 |
| NPC | 마리·레온 2명. 카일·노아는 전체 사건 확장에 배치 |
| 잔향 | 동일 방의 정지된 과거 1개 |
| 단서 | 조각 1개·배치 기록 1개, 증언·관찰 포함 카드4개 |
| 과제 | 시야로 목격 주장을 검증하는 기능 시연 1개 |
| 카메라 | 5가지 전부, 조각 뒷면의 공전·휠 확대 포함 |
| 연출 | 가장자리 안개, FOV 흡입, 안전한 현재 복귀 |
| 마무리 | 주장·근거 제출, 수정 진술, 조사 결과·재시작 |
| 길이 | 첫 플레이 약3~5분. 실제 테스트로 확인 |

이 단계의 결과는 목격 검증이다. 마리가 투여했지만 죽이지 않았다는 첫 반전까지 실제로 플레이하려면 투여 후 생존·행위 순서의 독립 증거가 먼저 필요하다. 그것이 정해지기 전에는 해당 반전까지 구현했다고 표시하지 않는다.

## 확장 순서

기본 시제품 안정 후 네 용의자의 고정 대사와 프로필을 추가할 수 있다. 다음으로 마리의 투여·잘못된 확신, 마지막으로 노아의 실제 살해·과거 방화를 입증하는 자료를 연결한다. 단서 개수는 증거 역할을 정한 뒤 산정한다.

FMOD는 사운드에, Assimp는 외부 모델을 쓸 때 사용한다. 도구의 구체적인 조건과 자료 출처는 도입 시 확인한다. 음성 연기·실시간 과거·넓은 화재 맵·전투·NPC 이동·저장/불러오기는 기본 범위가 아니다.

범위를 줄여도 카메라5가지·한글·복귀·충돌·추리 공정성은 유지한다. 일정에 맞지 않으면 기술/조사 시제품이라고 정직하게 설명한다.
