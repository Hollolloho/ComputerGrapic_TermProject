# 작은 단계 구현 체크리스트 v2.1

갱신일: 2026-10-07. 이야기 기준은 마리와 에드윈의 과거 구호 기록 은폐를 다룬 v2.1 초안이다. 기본 구현 순서와 완료 체크는 유지한다. 기존 긴 목록을 기능별 파일로 분리하고 목표 범위를 줄였다.

## 한 번의 작업 방식

1. 선행 작업이 완료된 ID 하나를 고른다.
2. 한 가지 동작만 수정한다.
3. 빌드하고 표의 확인 결과를 실제 실행한다.
4. 통과하면 체크한다. 막히면 ID-a, ID-b처럼 더 나눈다.
5. 오늘 결과와 다음 ID를 기록한다.

서술 설계는 [문서 시작점](docs/game/README.md)을 참고한다. 이전 168개 목록은 [보관본](docs/archive/2026-10-02/GAME_IMPLEMENTATION_CHECKLIST.md)에 남겼다. 새 목록의 체크를 구현 완료로 자동 이월하지 않는다.
