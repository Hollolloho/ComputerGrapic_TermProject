# 04. 잔향·안개·흡입·추론

먼저 상태 교체와 복귀, 그다음 연출, 마지막으로 주장 제출을 붙인다. [입력 계약](../04_ECHO_AND_INPUT.md)을 함께 확인한다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| [ ] | E001 | A | G024 | Present/Echo 월드 상태 변수 추가 | 개발 표시로 구분 |
| [ ] | E002 | B | E001 | 과거의 책장을 창 앞에 배치 | 과거 상태에서 책상이 가려짐 |
| [ ] | E003 | A | E002 | 활성 배치에 맞춰 충돌·조사 데이터 전환 | 보이는 책장과 막히는 위치 일치 |

EV_TESTIMONY는 G016의 대화에서 G018의 획득 기능으로 기록한다. 이를 카드 수첩에 연결할 때 G016 아래 더 작은 입력 항목으로 추가해도 된다. 모든 콘텐츠가 연결된 것은 E026 이후 실행해서 확인한다.
