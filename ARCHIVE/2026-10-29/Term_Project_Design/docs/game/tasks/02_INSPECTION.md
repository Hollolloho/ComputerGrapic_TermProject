# 02. 필수 공전 상세보기

CAM_ORBIT를 완성하고 상세보기 확대까지 연결한다. 게임 사건 완료 뒤로 미루지 않는다. 고정 큐브를 표시용 조각으로 사용하면 된다.

한 행을 변경한 뒤 빌드·실행하고 확인 결과를 만족하면 체크한다. 한 번에 여러 행을 구현하지 않는다. 선행 조건은 다른 파일의 ID도 포함한다. A는 C++ 4/10, B는 C++ 2/10 개발자다.

| 상태 | ID | 담당 | 선행 | 한 번에 할 변경 | 완료 확인 |
|---|---|---|---|---|---|
| [ ] | O001 | A | C018 | Explore/Inspection 화면 모드 분리 | 개발키로 모드 표시만 전환 |
| [ ] | O002 | A | O001 | Inspection에서 별도 배경과 큐브 렌더링 | 세계 원본 물체가 바뀌지 않음 |
| [ ] | O003 | A | O002 | 단서 중심 pivot 값 하나 정의 | 큐브 중심이 pivot과 일치 |
| [ ] | O004 | A | O003 | 고정 radius의 InspectCamera 로컬 위치 정의 | 중심에서 떨어진 카메라로 큐브를 봄 |
| [ ] | O005 | A | O004 | pivot 부모×로컬로 상세보기 View 계산 | 부모 중심을 옮기면 단서와 카메라 기준이 함께 이동 |
| [ ] | O006 | A | O005 | 드래그로 수평 공전각만 변경 | 대상 고정, 카메라가 옆면을 봄 |
| [ ] | O007 | A | O006 | 제한된 수직 공전각 추가 | 앞·위·아래를 보되 극점에서 뒤집히지 않음 |
| [ ] | O008 | B | O007 | 표시 큐브 뒷면에 큰 삼각 표식 배치 | 공전으로 뒷면을 볼 수 있음 |
| [ ] | O009 | A | O008 | 휠로 Inspection FOV 변경 | radius는 고정, 확대만 변함 |
| [ ] | O010 | A | O009 | Inspection FOV 상하한 적용 | 휠 연타로 잘못된 투영이 되지 않음 |
| [ ] | O011 | A | O010 | 상세보기 입력과 탐색 입력 차단 분리 | 드래그가 플레이어 yaw를 바꾸지 않음 |
| [ ] | O012 | A | O011 | 열기 전 탐색 데이터를 저장 | world모드·위치·yaw·pitch·FOV 보관 |
| [ ] | O013 | A | O012 | Esc로 상세보기 닫고 복원 | 열기 전 위치·방향·FOV로 돌아옴 |
| [ ] | O014 | B | O013, B012 | E로 뒷면 표식 관찰 문구 표시 | 범인·정답 판정 없이 표식 정보만 읽음 |
| [ ] | O015 | 공동 | O014 | 다섯 필수 카메라 기능 첫 시연 | 확대·이동·자전·공전·부모 전부 실제 동작 |

완료 직후 두 PC에서 실행해 본다. 상세보기는 세계 전체를 공전하는 모드가 아니다. 공간 추리의 가림 관계를 우회하지 않는다.
