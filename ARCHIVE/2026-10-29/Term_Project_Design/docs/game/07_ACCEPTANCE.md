# 검증·제출 기준

현재 문서 단계이며 실행 검증은 아직 하지 않았다. 구현 후 아래 조건을 직접 확인한다.

## 필수 카메라 확인

| ID | 실행 확인 |
|---|---|
| CAM_ZOOM | 상세보기에서 휠을 돌릴 때 FOV만 변함. 닫으면 탐색 FOV 복원 |
| CAM_MOVE | WASD로 위치 변화, 벽과 책장을 통과하지 않음 |
| CAM_SELF | 마우스만 움직일 때 위치 고정, 방향 변화 |
| CAM_ORBIT | 단서 고정, 카메라가 중심에서 같은 거리로 좌우·상하 공전 |
| CAM_PARENT | 부모 위치 변화가 눈 카메라에 적용되고 로컬 눈높이는 유지 |

로그 숫자만 바뀌는 것이 아니라 실제 화면도 확인한다. 공전은 물체 회전으로 대체하지 않는다. 성공적인 빌드와 렌더링·입력 검증을 구분해 보고한다.

## 잔향과 진행

- [ ] 동일 목격 위치에서 현재는 책상이 보이고 해당 과거는 가려진다.
- [ ] 잔향의 사실과 작업 기록의 유지 기간이 맞는다.
- [ ] 이보의 수정 진술이 새 초자연 능력이나 유죄 자백을 추가하지 않는다.
- [ ] 과거의 벽·책장 표시와 충돌이 일치한다.
- [ ] 10회 왕복 후 위치·yaw·pitch·FOV가 복구된다.
- [ ] R 연타, 전환 중 Tab/Esc, 상세보기 중 R이 잘못된 전환을 만들지 않는다.
- [ ] 중앙 시야와 UI는 안개에 가려지지 않는다.
- [ ] 상세보기 닫기 후 탐색·과거·수첩 모드가 정확히 복원된다. 기본 설계는 현재에서만 상세보기 허용.
- [ ] 필수 증거 없이 주장 정답만 고르면 과제가 완료되지 않는다.
- [ ] 증거 선택 순서와 수집 순서를 바꿔도 재시도·완료가 가능하다.
- [ ] 재시작 시 획득·추론·모드가 초기화된다.
- [ ] 처음 플레이하는 사람이 모순을 자기 말로 설명한다.

판정 함수에 분기·집합 비교가 생기면 정답·오답·근거 부족의 작은 실행 가능한 검사를 남긴다. 그래픽·공간·안개는 실제 플레이 체크로 확인한다. 문서만 변경한 현재 작업에 제품 테스트 성공을 주장하지 않는다.

## 전체 사건 확장 시 추가 검토

- [ ] 옛 접수소 장면의 장소와 안내판 유지 기간을 독립 기록으로 확인한다.
- [ ] 요청의 제때 접수·배분 판단·기록 조작을 구분하고, 에드윈과 수정 행위를 연결하는 물증을 제공한다.
- [ ] 지원이 있었다면 아이가 반드시 살았다고 단정하지 않는다.
- [ ] 과거 은폐의 증거를 마리의 현재 살인 증거로 대체하지 않는다. 전체 시간표와 R01 보존 시점이 맞는다.
- [ ] 잔향 봉쇄·회수·의존을 마리의 살인 동기로 다시 넣지 않는다.
- [ ] 최종 결말은 기록 정정과 살인 책임을 함께 남기며 즉각적인 용서·화해를 보장하지 않는다.

이 목록은 선택 확장 검토 조건이다. 기본 제출본 완료를 위해 추가 잔향·카드·NPC·최종 결말을 요구하지 않는다.

## 제출

Release x64, 필요한 런타임 DLL, assets, 조작법, 실제 사용 자료의 출처, 알려진 제한을 함께 묶는다. IDE 밖과 다른 PC에서 실행한다. 개인 절대 경로와 SDK 전체 폴더에 의존하지 않는다. 필요한 C++ 런타임도 배포 환경에서 확인한다.

발표는 부모 관계·WASD 이동·제자리 자전, 단서 공전·확대, 안개·흡입 잔향, 목격 위치 시야 비교, 주장 제출 순으로 2~3분 시연한다.

기본 제출본은 첫 조사 과제 시제품이라고 설명한다. 살인 전체를 해결하지 않았다면 완성형 살인 수사 게임이라고 발표하지 않는다. 교수의 구체적인 평가표는 아직 받지 않았으므로 합격을 보장하지 않는다.
