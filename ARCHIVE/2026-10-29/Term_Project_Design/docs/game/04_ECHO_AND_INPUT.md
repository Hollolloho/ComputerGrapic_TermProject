# 잔향·연출·입력 계약

## 상태를 두 축으로 나누기

월드 상태: Present, Entering, Echo, Exiting. 화면 모드: Explore, Dialogue, Notebook, Inspection, Report, Pause.

일반 진입은 Present+Explore일 때 가까운 잔향 대상에서만 허용한다. 대화·수첩·상세보기 중 R 요청은 받지 않는다. 이탈은 Echo+Explore에서 R로 한다. 현재/과거 모드가 수첩을 열었다는 이유로 바뀌지 않는다.

상세보기는 Present에서만 연다. 첫 버전에서 과거 중 상세보기 중첩을 만들지 않는다. Inspector 닫기 전에는 월드 전환이 발생하지 않는다.

## 조작

| 입력 | Explore | UI 또는 전환 중 |
|---|---|---|
| WASD·마우스 | 걷기·둘러보기 | 탐색 정지 |
| E | 조사·대화·관찰 기록 | 선택 확인 용도로 쓰려면 일관되게 연결 |
| R | 잔향 진입 또는 이탈 | 무시 |
| Tab | 수첩 열기 | Notebook에서 닫기. 전환 중 무시 |
| 1~4·Enter | 수첩·주장 화면에서 근거 선택·제출 | 해당 화면에서만 처리 |
| 드래그·휠 | Inspection에서 공전·확대 | 다른 모드에서 공전에 전달하지 않음 |
| Esc | Pause | 최상위 화면 닫기. 전환 중에는 완료 후 Pause 요청 |

종료는 Pause의 명시적인 종료 선택으로 한다. 창 닫기 버튼도 정상 정리 후 종료한다. 단축키를 안내 문구와 맞춘다.

## 전환 최소 연출

총 진입 시간의 시작값은 1.0~1.2초다. 0.2초까지 테두리 안개가 짙어지고, 0.2~0.6초에 FOV가 기본 65도에서 약 57도로 좁아진다. 약 0.65초에서 과거 배치·충돌·시작 위치를 한 번 적용한다. 마지막에 FOV를 복원하고 이동을 재개한다.

안개 무늬는 테두리에서 중심 방향으로 흐르게 하되 중앙 알파는 낮게 유지한다. 과거 탐색 중에는 바깥쪽 약 15~20%에 옅게 남는다. 전진·흔들림은 탐색 중 계속되지 않는다. 실제 카메라 전진은 기본 제출 목표에서 제외하고 FOV와 안개로 흡입감을 만든다.

이탈은 약 0.6초의 짧은 역전환 후 현재 카메라 데이터를 복원한다. 수치는 실제 체감으로 조정한다. 중앙이 선명하므로 장면 교체를 완전히 숨기는 연출은 아니다.

## 상태 저장

진입 전에 playerPosition, yaw, pitch, FOV와 활성 월드 모드를 저장한다. 과거에서 걸어간 좌표를 현재로 그대로 옮기지 않는다. Inspection의 별도 카메라 데이터는 탐색 데이터를 수정하지 않는다.

과거 안전한 시작 지점을 지정한다. 표시·충돌·조사 데이터는 같은 순간의 배치를 사용한다. 저장 상태는 중복 R 입력으로 덮어쓰지 않는다.

타이머가 교체 시점을 넘을 때 한 번만 교체한다. 특정 프레임에 0.65초가 정확히 찍혀야 교체되는 코드는 쓰지 않는다. 전환 완료 시 기본 FOV·안개 강도를 명시적으로 설정한다.

포커스 상실·Pause에서는 타이머와 이동을 멈춘다. 복귀 직후 마우스 좌표 기준을 다시 잡고 큰 경과 시간을 처리한다. 프레임 수로 시간을 계산하지 않는다.

## 가독성과 안개

불투명 3D, 테두리 안개, UI 순으로 그린다. 과거 벽과 책장을 반투명하게 만들지 않는다. 한글과 조준점에 안개가 덮이지 않도록 한다. 효과 줄이기 옵션은 흡입 FOV 변화만 생략한다. 상세보기 휠 확대는 남아 있어 필수 확대를 확인할 수 있다.
