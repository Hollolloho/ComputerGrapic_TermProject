# 내일도 와줄 거지 — 기획안 v1.3

> 확인된 방향: OpenGL 3D 1인칭 추리, 중세 유럽풍 마을, 실제 초자연적 존재, 상실과 의존을 중심으로 하는 사건. 잔향은 실제 과거의 정지된 3D 공간을 보여주며, NPC의 기억 손실은 증언의 불확실성에 영향을 준다. 플레이어가 직접 장면과 증언을 대조한다.
> 제작 조건: 2명, 2~3주, 모델링 자산 없음. OpenGL 숙련도 0/10·0/10, C++ 숙련도 4/10·2/10. 사운드는 FMOD, 외부 모델을 가져오는 경우 Assimp를 사용한다. 음성 연기는 필요하지 않다.
> 검토 단계: 상세 범행 시간표, 최종 단서 배치와 독립 증거. 기존 음성 재생 트릭은 과거 공간과 불완전한 증언을 대조하는 방식으로 재설계한다. 잔향 진입에는 화면 가장자리 안개와 빨려 들어가는 듯한 전환을 사용한다.

## 1. 핵심 경험

**사람은 잘못 기억할 수 있지만 잔향은 없었던 장면을 보여주지 않는다.** 다만 잔향 하나가 사건의 모든 것을 설명하지는 않는다.

플레이어는 증언을 듣고, 마을에 남은 잔향 조각에서 과거의 장면을 얻고, 서로 맞지 않는 시간·행동·사물을 직접 비교한다. 목표는 조각 수집 자체가 아니라 “이 장면이 무엇을 입증하고, 무엇까지는 알 수 없는가”를 판단하는 것이다.

## 2. 전설과 실제 존재

산간 마을 네르에는 “돌은 우리가 잊은 얼굴을 기억한다”는 전설이 있다. 주민들은 예배당의 검은 돌에서 떠난 사람의 모습을 본다. 외지인에게는 기이한 현상이지만 주민에게는 마을을 떠나지 못할 이유다.

실제로는 돌 틈에 자라는 군체형 생물 **잔향**이 주변의 모습을 보존한다. 사람들은 보존된 장면을 보기 위해 오래 머물고, 그 과정에서 자신의 기억을 조금씩 잃는다. 죽은 사람을 되살리거나 현재를 보여주는 존재는 아니다.

### 추리에 사용할 고정 규칙

| 규칙 | 게임에서의 의미 |
|---|---|
| 잔향은 그 자리에서 실제로 일어났던 장면만 보존한다 | 사람·물건·행동을 합성하거나 기억 속 환상을 사실처럼 보여주지 않는다 |
| 한 조각은 사건 설계에서 정한 하나의 정지된 3D 장면을 보여준다 | 같은 조각을 다시 열어도 내용이 바뀌지 않는다. 랜덤 단서는 없다 |
| 보존된 공간 밖의 일, 인물의 의도, 정확한 시각은 알려주지 않는다 | 장면은 참이지만 플레이어의 해석은 틀릴 수 있다 |
| 조각을 옮겨도 원래 장면은 유지된다 | 발견 장소가 장면의 발생 장소인 것은 아니다. 배경으로 대조한다 |
| 기억 손실은 오랜 노출에서 생기며 사람마다 누적 정도가 다르다 | 증언의 날짜·순서가 잘못될 수 있다. 모든 NPC가 틀리는 것은 아니다 |
| 잔향은 기억을 새로 심거나 사람을 조종하지 않는다 | 실제 기억 일부를 잊은 사람이 자신의 추측으로 빈 부분을 메울 수 있다 |

과거 공간 안의 달력, 물건 상태, 창밖 풍경 등은 실제로 그 장면에 존재했던 정보여야 한다. 편의상 날짜·범인 이름·의도 자막을 붙이지 않는다. 물체를 지나치게 작게 만들거나 어둡게 숨기는 방식으로 난도를 높이지 않는다.

잔향이 “거짓이 없다”는 사실과 “모든 것을 보여준다”는 주장은 다르다. 예를 들어 칼을 든 사람이 보인다는 사실만으로 살인을 저질렀다고 확정할 수 없다. 반대로 과거 장면 자체가 가짜였다는 결말도 사용하지 않는다.

## 3. NPC의 증언: 기억 손실을 실제 추리 장치로 사용

증언의 모순에는 세 원인이 있다. 플레이어에게 원인 라벨을 미리 보여주지 않는다.

- 정확한 기억: 실제로 본 것을 맞게 말한다.
- 잘못된 기억: 장면은 기억하지만 날짜나 순서를 잊어 다른 날의 일과 혼동한다.
- 의도적인 거짓말: 자신에게 불리한 행동을 감추려고 말을 바꾼다.

각 NPC가 무엇을 잊었는지는 대본 작성 때 고정한다. 플레이어가 정답에 가까워질 때마다 기억 손실을 추가하지 않는다. 재질문하면 같은 기록을 다시 볼 수 있고, 증거 제시로 바뀐 진술은 이전 진술 옆에 추가한다.

예시 퍼즐: 이보는 “어제 저녁에도 에드윈이 예배당에서 기록하고 있었다”고 확신한다. 한 잔향에는 에드윈과 아직 깨지지 않은 창이 보인다. 별도의 수리 기록으로 창이 사건 전날 이미 깨졌음을 알 수 있다면, 이 장면은 사건 당일의 생존 증거가 아니다. 단, 장면의 날짜가 오래됐다는 것만으로 이보의 다른 목격까지 부정할 수는 없다. 이보가 그 장면과 동일한 물건 배치·행동을 설명한다는 연결을 함께 제공해야 한다.

이 예시는 날짜 혼동을 설명하는 설계 예시다. 실제 범행 시간표에서 단서들의 날짜를 확정한 뒤 사용한다.

## 4. 이야기와 등장인물

플레이어는 주민들의 기억 이상을 조사하러 온 외지 조사관이다. 먼저 조사를 진행하던 기록관 **에드윈**이 기록실에서 죽은 채 발견된다. 주민들의 마지막 목격 시각은 일치하지 않는다.

| 인물 | 표면 역할 | 수사에서의 역할 |
|---|---|---|
| 여관 주인 마라 | 탐정의 숙소를 제공하는 친절한 조력자 | 잔향에 의존하며 살인을 감추기 위해 의도적으로 거짓말한다 |
| 종지기 이보 | 예배당을 관리한다 | 오래 노출되어 일부 목격의 날짜를 혼동한다 |
| 석공 베른 | 예배당의 수리와 봉쇄를 맡는다 | 조각을 몰래 떼어준 거래를 숨긴다. 작업 기록은 시간 기준이 된다 |
| 마라의 딸 리아 | 여관 일을 돕는다 | 어머니의 기억 손실을 알고 에드윈에게 도움을 청했다 |

### 마라의 동기

마라는 오래전 병으로 어린 아들을 잃었다. 에드윈은 그 죽음과 무관하다. 마라가 매일 보는 잔향에는 예배당 문 앞에서 돌아보며 손을 내미는 아들의 모습이 남아 있다. 마라는 그날 아이가 “엄마, 내일도 와줄 거지?”라고 물었다고 이야기한다. 이는 마라의 회상이며 잔향이 말을 재생하는 것은 아니다.

에드윈은 마라가 아들의 모습을 보는 동안 살아 있는 딸과의 기억까지 잃는다는 것을 알아내고 예배당 봉쇄와 조각 회수를 추진한다. 마라에게는 자신을 버티게 해준 마지막 연결이 끊기는 일이다. 설득이 실패한 날 그녀는 에드윈을 살해한다.

에드윈은 숨겨진 악인이 아니다. 마라의 감정을 이해하는 것과 살인의 책임을 판단하는 것은 분리한다. 결말에는 같은 아들의 정지된 모습을 다시 보여주고, 곁에 있는 딸에게 마라가 시선을 돌리는 장면을 텍스트와 단순 화면 전환으로 표현한다.

## 5. 사건을 푸는 구조

음성으로 가짜 생존 시점을 만드는 이전 트릭은 폐기한다. 현재 중심은 **틀린 목격 날짜를 바로잡고, 사실인 장면들의 순서와 맥락을 복원하는 것**이다.

1. 이보의 목격 증언 때문에 에드윈이 늦은 시각까지 살아 있었다고 여긴다. 마라는 그 시각 다른 사람과 함께 있었다고 주장한다.
2. 과거 장면과 수리 기록을 비교해 목격 날짜의 혼동을 발견한다. 저녁의 알리바이가 실제 범행 가능 시간대를 설명하지 못하게 된다.
3. 다른 잔향에서 마라와 에드윈이 기록실에서 만났다는 사실을 확인한다. 방문 부정은 깨지지만, 만남만으로 살인을 확정하지 않는다.
4. 마지막 잔향과 현장 단서를 함께 읽어 물건의 이동 및 범행 전후 행동을 복원한다. 마라의 동기와 함께 최종 사건 설명을 제출한다.

세 잔향의 목표 역할은 각각 **시간 오해 교정 / 방문 확인 / 행동 순서 확인**이다. 세 번째 장면에 살인 장면 전체를 그대로 넣어 수집만 하면 끝나는 구조는 피한다.

아직 확정하지 않은 부분: 마지막 과거 장면의 정확한 내용, 사인과 흉기, 생존 확인부터 사망 발견까지의 독점적 접근 기회, 다른 용의자를 배제하는 근거. 이것들을 정하기 전에는 유일한 정답이 보장되는 완성 퍼즐이라고 보지 않는다. 잘못된 알리바이와 방문 사실만으로 유죄를 판정하지 않는다.

## 6. 플레이어가 직접 추리하는 UI

- 물건을 조사하면 관찰 내용을, NPC와 대화하면 증언을 수첩에 기록한다.
- 잔향 조각을 찾으면 대응하는 장소의 진입 지점에서 과거 공간으로 들어간다. 인물과 물체는 정지해 있고 플레이어만 이동·관찰한다. 발견한 잔향에는 다시 진입할 수 있다.
- 과거 공간을 관찰하면서 선택한 증언 한 개를 화면 한쪽에 띄울 수 있다. 수첩과 자막은 안개에 가려지지 않게 한다.
- 발견 즉시 “이보의 증언은 거짓” 같은 해설이나 정답 연결선을 표시하지 않는다.
- 수첩 정렬은 발견 순서로 두고, 자동으로 사건 시간순을 완성해 주지 않는다.
- 추론 제출 시 플레이어가 관련 카드와 주장을 직접 선택한다. 자유 문장 입력과 자동 자연어 판정은 구현하지 않는다.
- 틀린 제출은 단서를 빼앗지 않고 다시 생각하게 한다. 자동 정답 공개 대신 요청했을 때만 단계별 힌트를 준다.

첫 버전은 드래그 연결 보드 대신 버튼으로 증거 두 개를 선택한다. 복잡한 UI 없이도 어떤 증거를 연결할지는 플레이어가 결정할 수 있다.

### 6-1. 3D 공간이 추리에 필요한 이유

플레이어는 목격자가 서 있었다는 자리에 직접 서서 과거의 시야를 확인한다. 예를 들어 현재는 창을 통해 책상이 보이지만, 과거에는 높은 책장이 창을 가리고 있었다면 “그 자리에서 책상 앞 사람을 봤다”는 증언을 검토할 수 있다. 그 다음 다른 날짜의 배치와 기록을 대조해 기억 착오인지 의도적인 거짓말인지 판단한다.

잔향은 시간여행처럼 체험하지만 이미 일어난 순간을 관찰하는 기능이다. 과거의 물건을 옮겨 현재를 바꾸거나 NPC와 상호작용하지 않는다. 전체 방과 목격 지점을 포함한 보존 범위를 미리 정하고, 범위 밖은 이동하지 못하게 한다. 현재 물체와 과거 물체를 동시에 겹쳐 시야를 혼란스럽게 만들기보다 과거 상태로 교체하고 색감과 안개로 구별한다.

### 6-2. 잔향 진입 연출 — 가장자리 안개와 흡입감

사용자 확정 방향: 과거 진입 시 화면 가장자리에 안개를 표시하고, 앞으로 빨려 들어가는 듯한 짧은 동작을 준다. 아래 시간과 수치는 구현 후 조정할 초깃값이다.

| 단계 | 대략적인 시간 | 화면과 조작 |
|---|---|---|
| 끌림 시작 | 0~0.2초 | 선택한 잔향을 중심으로 가장자리 안개가 짙어진다. 이동과 중복 진입 입력을 잠시 막는다 |
| 진입 | 0.2~0.6초 | 카메라 시야각을 조금 좁히고 제한된 거리만 전진시켜 장면이 가까워지는 느낌을 낸다. 안개 무늬는 중심으로 흐른다 |
| 장면 교체 | 0.6~0.85초 | 가장자리 안개가 가장 짙을 때 현재 물체 배치를 과거 배치로 전환하고 색감을 차갑게 바꾼다 |
| 안정화 | 0.85~1.2초 | 시야각을 평상시 값으로 되돌린다. 가장자리의 옅은 안개만 남기고 이동·시점 조작을 재개한다 |

과거를 탐색하는 동안 안개는 화면 바깥쪽 약 15~20% 영역에만 옅게 남긴다. 중앙의 물체와 글자는 선명하게 보인다. 안개는 미세하게 흐를 수 있지만 카메라 흔들림과 확대·축소는 진입이 끝나면 멈춘다. 기본안은 어두운 테두리에 회청색 안개가 얹히는 모습이며, 번쩍이는 백색 화면은 쓰지 않는다.

이탈 키를 누르면 더 짧은 역전환 후 현재로 돌아온다. 현재의 진입 전 위치·시점은 저장해 두었다가 복원한다. 과거 탐색 위치를 현재 좌표로 그대로 적용해 책장이나 벽 안에 나타나는 상황을 만들지 않는다. 수첩을 열거나 창 크기를 바꿔도 전환 상태가 중복 실행되지 않게 한다.

### 6-3. 구현 수준과 확인 항목

- 첫 구현은 화면 위에 그리는 가장자리 안개와 시야각 보간만 사용한다. 입체 안개, 유체 시뮬레이션, 화면 전체 왜곡은 필수 기능이 아니다.
- 안개는 화면 좌표의 가장자리 마스크와 천천히 움직이는 간단한 무늬로 표현한다. UI는 그 위에 그려 텍스트 가독성을 유지한다.
- 시야각의 초기 실험값은 평상시 65도에서 진입 중 57도 정도다. 카메라 전진은 여유가 있는 진입 지점에서 짧게만 적용하고, 충돌 안전성을 확인하기 전에는 시야각 변화만 쓴다.
- 상태는 현재 / 진입 중 / 과거 / 이탈 중으로 나눈다. 시간 기반 보간을 사용해 프레임 속도에 따라 전환 시간이 달라지지 않게 한다.
- 과거 장면마다 안전한 시작 위치를 정한다. 현재·과거의 충돌 배치는 해당 상태와 일치시킨다.
- 반복 진입, 벽 가까이에서의 진입, 중복 키 입력, 복귀 위치, 가장자리 단서 가독성을 확인한다. 전환이 부담스러우면 이동·시야각 변화 없이 짧은 안개 전환만 사용하는 설정을 둔다.

연출보다 먼저 현재/과거 상태 전환과 시야 퍼즐을 완성한다. 그다음 가장자리 안개, 시야각 변화, 안전한 짧은 전진 순서로 더한다. 이 문서의 수치는 아직 실행 화면에서 검증하지 않았다.

### 6-4. 카메라 기능 적용 점검

2026-10-01 요청에 따라 확대·자전·이동·공전·부모 관계를 카메라 기준으로 정리한다. 확대는 잔향 진입의 FOV 변화, 자전은 제자리 마우스 둘러보기, 이동은 WASD 탐색으로 기존 계획에 포함된다. 부모 관계는 플레이어 아래 눈 카메라를 붙여 위치·방향을 전달하는 구조로 제안한다.

공전은 기존 계획에 없으므로 **획득한 단서의 별도 3D 상세보기**를 추가 후보로 둔다. 물체를 고정하고 카메라가 그 중심을 돌아 옆면의 각인·파손을 관찰하는 방식이다. 공간 전체를 공전시켜 벽 너머를 보는 기능은 시야 추리를 우회하므로 사용하지 않는다. 첫 사건을 완성한 뒤 추가 여부를 결정하며, 상세보기는 기본 1인칭 탐색 중 잠시 여는 조사 화면이다.

각 기능은 구현 완료가 아니라 적용 위치의 점검이다. 개발서 6.4절과 구현 체크리스트의 K001~K012에 설명과 확인 절차를 추가했다.

## 7. 첫 제작 범위

2~3주에 OpenGL 학습과 게임 구현을 함께 해야 하므로, 첫 완성 목표는 **5~10분의 짧은 사건**으로 낮춘다. 완성 가능성은 하루 실제 작업 시간과 초기 학습 속도에 따라 달라진다.

| 항목 | 최소 목표 |
|---|---|
| 공간 | 하나의 작은 3D 구역. 광장 모서리, 기록실, 예배당 벽감을 단순 도형으로 구성 |
| NPC | 고정 위치 4명, 대화별 핵심 진술 2~3개. 걷기·표정 애니메이션 없음 |
| 잔향 | 먼저 방 하나의 현재/과거 상태 전환과 시야 퍼즐 1개를 완성. 일정이 허용되면 같은 공간의 잔향을 총 3개로 확장 |
| 다른 단서 | 물리 단서·문서 2~3개. 과거 공간과 함께 읽어야 의미가 완성되게 구성 |
| 추론 | 핵심 추론 2개와 최종 지목·근거 선택 |
| 조작 | WASD, 마우스 시점, E 조사, 수첩 열기, 메뉴 클릭 |
| 결말 | 텍스트와 잔향 장면으로 마무리되는 결말 1개 |

제외: 전투, 실시간 낮밤, NPC 이동 AI, 실시간 기억 시뮬레이션, 저장/불러오기, 음성 연기, 동영상, 과거 인물과의 대화·물체 이동, 자유 배치 추리 보드. NPC의 기억 손실은 정해진 대사와 상태로 구현한다. 플레이어의 기억이나 수첩 기록은 지우지 않는다.

## 8. 그래픽·오디오·라이브러리

현재 폴더에서 확인했던 GLFW·GLEW·GLM 기반을 활용한다. 처음에는 평면·상자로 된 장면과 고정 NPC로 시작한다. 동일한 방의 현재·과거 물체 배치와 표시 상태를 전환한다. 과거 NPC의 행동이나 시간을 시뮬레이션하지 않는다. 플레이어는 과거 상태의 공간에서 이동하며 가려짐과 목격 시야를 확인한다.

현재와 과거는 공통 공간 좌표와 기본 모델을 공유한다. 벽·창·책장 등의 배치 차이를 단서로 사용한다. 주요 인물은 이름표나 얼굴 디테일만으로 식별하게 하지 않고, 실루엣·옷의 무늬·소지품을 함께 일관되게 사용한다. 살인범 식별에 쓰는 특징은 별도 근거로 확인한다.

- **FMOD:** 사용 예정. 배경음 하나와 상호작용 효과음 정도부터 넣는다. 소리가 없어도 사건을 풀 수 있어야 한다.
- **Assimp:** 외부 OBJ 모델을 가져올 때 사용 예정. 처음 구현할 도형에는 필요하지 않으므로 게임 진행이 된 뒤 도입한다.
- **텍스트·UI:** 아직 미정. 한글 문장 출력과 버튼 입력을 첫 단계에서 검증한다. 게임 전체에 쓸 라이브러리는 그 결과로 고른다.
- **이미지 로딩:** 문서 그림이나 선택적으로 사용할 안개 텍스처를 읽는 기능이다. 잔향 자체는 3D 공간으로 표현한다. 모델 로딩과는 별도 항목으로 다룬다.
- **에셋 사용 조건:** 사용자는 비상업 프로젝트에서 사용 가능한 자료를 허용한다. 실제 채택 시 각 파일의 사용·수정·배포·표시 조건을 확인하고 출처를 기록한다. FMOD 등 도구의 이용 조건과 음악·폰트·이미지의 조건은 별도로 확인한다. 현재 특정 에셋의 사용 권한을 검증한 상태는 아니다.

이 문서에서는 새 라이브러리 버전이나 구체적인 이용 허가를 확정하지 않는다. 설치·배포 단계에서 공식 문서와 해당 에셋의 라이선스를 확인한다.

## 9. 숙련도에 맞춘 제작 순서

| 구간 | C++ 4/10 개발자 | C++ 2/10 개발자 | 완료 기준 |
|---|---|---|---|
| 1~3일 | 기존 창 실행, 카메라, 단순 공간 | 기초 C++ 복습, 대사·증거 데이터 작성, 과거 물체 배치 초안 | 직접 걸어 다니고 한글 한 문장을 볼 수 있음 |
| 4~7일 | 조사 판정, UI와 게임 상태 연결 | 고정 대화 화면, 증거 목록 구성 | NPC 대화 → 과거 공간 전환 → 시야 대조 → 수첩 재열람 |
| 2주차 | 추론 제출, 최종 지목, 오류 수정 | 과거 배치·대사 입력, 수동 플레이 점검 | 도움 없이 처음부터 끝까지 진행 가능 |
| 3주차 확보 시 | 충돌·입력·가독성 개선, FMOD 연결 | 증언의 논리 점검, 외부 테스트 기록 | 막힘 수정 후 제출본 확보 |

역할은 경계가 고정된 분업보다 작은 기능 단위로 합치는 방식으로 운영한다. 낮은 숙련도의 개발자에게 별도 UI 엔진 전체를 맡기지 않는다. 두 사람이 같은 화면을 함께 실행하는 시간을 초반부터 확보한다.

첫 주 말에도 이동·대화·현재/과거 전환이 연결되지 않으면 장소와 연출을 줄인다. 추리 규칙을 늘리거나 Assimp 모델 도입으로 시간을 쓰지 않는다. 테스트는 초심자가 해답을 설명할 수 있는지, NPC의 기억 손실을 핑계로 모든 증거를 불신하게 되지는 않는지 확인한다.

## 10. 다음 작업

라이브러리와 숙련도는 확인되었다. 잔향은 과거의 3D 공간을 탐색하는 방식으로 갱신되었다. 다음에는 첫 시야 퍼즐의 현재·과거 배치와 사건 시간표를 함께 설계한다. 각 잔향마다 다음을 명시한다.

1. 실제로 보이는 것.
2. 관련 NPC가 주장하는 것.
3. 다른 증거와 결합해 입증할 수 있는 것.
4. 그 장면으로는 알 수 없는 것.
