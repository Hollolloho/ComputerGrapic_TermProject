# 내일도 와줄 거지 — 프로젝트 문서

갱신일: 2026-10-29. 현재 이야기 기준은 **마리의 살인 시도와 노아의 실제 살인을 분리하는 머더미스터리**다.

- [STORY](STORY/README.md): 줄거리, 용의자, 과거 사건, 현재 사건, 잔향 단서와 미확정 사항.
- [DEVELOPMENT](DEVELOPMENT/README.md): 범위, 카메라, 상태, 디자인 패턴, 일정, 작은 구현 작업.
- [ARCHIVE](ARCHIVE/README.md): 이전 이야기와 문서 원문. 현재 설정과 구현 요구로 사용하지 않는다.

마리는 살해하려고 약을 넣었지만 실제 사망을 일으킨 사람은 노아다. 마리는 자신이 죽였다고 믿고 숨긴다. 레온과 카일은 각각 과거 의료·조사 은폐를 감춘다. 개발자는 이 사실을 알지만 플레이어에게 처음부터 공개하지 않는다.

OpenGL 확대·이동·자전·공전·부모 관계는 모두 필수다. 문서 재정리는 구현 완료를 뜻하지 않으며 작업 체크를 자동 완료하지 않았다.
