# 첫 전투 모듈: 탄환 이동과 첫 충돌

윤형균의 `feature/yoon-combat` 브랜치에서 준비한 독립 모듈이다. 카메라·렌더러·시간 시스템을 새로 만들지 않고 연결할 계산을 제공한다. 현재 빈 게임 창의 화면과 조작은 바꾸지 않는다. 사격 입력·실제 피해·무기 파손·적 AI·보스는 아직 구현하지 않았다.

## 제공하는 기능

- `MakeProjectile`: 월드 시작점과 방향·속도·발사 무기 ID를 받아 탄환 생성. 방향 길이에 관계없이 지정한 속도를 사용한다.
- `FindFirstHit`: 이전 위치에서 새 위치까지 선분과 월드 좌표 AABB의 교차를 검사해 가장 가까운 충돌 하나를 반환한다. 얇은 벽을 한 프레임에 넘어도 검사한다.
- `AdvanceProjectile`: 공용 `gameDt`로 이동하고 첫 충돌점에서 탄환을 비활성화한다. 같은 탄환으로 피해 이벤트를 다시 만들지 않는다.
- 벽·장갑·무기·본체 종류와 대상 ID를 반환한다. 정확히 같은 거리는 벽 → 장갑 → 무기 → 본체 순, 같은 종류는 작은 ID를 우선한다.

## 친구 코드와 연결할 데이터

| 전달 방향 | 데이터 |
|---|---|
| 카메라 → 전투 | 발사 시작점과 바라보는 월드 방향 |
| 시간 → 전투 | 공통 `gameDt`. 전투 안에서 독립적으로 시간 배율을 계산하지 않는다. |
| 장면 → 전투 | 벽·적 몸·무기의 월드 AABB, 고유 ID, 활성 상태 |
| 전투 → 장면 | 첫 충돌 대상·종류·위치와 발사 무기 ID |

```cpp
#include "combat.h"

// 새 클릭을 한 번 감지했고 발사가 허용된 경우에만 생성한다.
auto projectile = aegis::combat::MakeProjectile(
    cameraPosition, cameraForward, bulletSpeed, equippedWeaponId);

// 매 프레임 살아 있는 탄환마다 호출한다.
if (projectile) {
    if (auto hit = aegis::combat::AdvanceProjectile(*projectile, gameDt, colliders)) {
        // hit->kind에 따라 벽 효과 또는 피해를 한 번 처리한다.
        // 명중 시 무기 파손은 sourceWeaponId와 현재 장착 ID를 비교한다.
    }
}
```

위 코드는 API 사용 예시다. 실제 탄환 목록·클릭의 눌림 순간·발사 제한·발사 성공 시간 신호는 후속 구현한다. 발사자 자신의 몸/무기는 호출자가 충돌 목록에서 제외하고, 적·플레이어 진영 필터도 호출자가 적용한다. 무기와 몸의 실제 첫 경계가 다르면 가까운 경계를 우선하며, 종류 우선순위는 정확히 같은 충돌 거리에서만 적용한다.

현재 범위는 **점 탄환 대 축 정렬 상자**다. 회전 물체는 월드 AABB로 감싸야 하고 정밀 메시·회전 상자 충돌은 제공하지 않는다. 움직이는 대상의 프레임 사이 궤적까지 검사하는 연속 충돌은 아직 없다. 탄환 수명·최대 사거리·목록에서 제거하는 동작은 연결 단계에서 추가한다.

## 검사 실행

Visual Studio 2026의 Developer PowerShell에서 저장소 루트를 열고 실행한다.

```powershell
msbuild tests/combat_tests.vcxproj /p:Configuration=Debug /p:Platform=x64
./build/combat-tests/Debug/combat_tests.exe
```

Release 검사는 위 두 줄의 `Debug`를 `Release`로 바꾼다. 테스트는 OpenGL 창이나 카메라가 필요 없다. 실패 시 종료 코드는 1이다.

검사 대상: 벽 뒤 표적 차단, 얇은 벽 통과 방지, 대상 배열 순서 무관, 비활성·잘못된 상자 제외, 선분 바깥 표적, 평행 선분, 내부 시작·끝점 명중, 중복 충돌 방지, 게임 시간·일시정지, 잘못된 발사 입력, 무기·몸 동일 거리, 발사 무기 ID 유지, 프레임 분할 이동 일관성.

실제 OpenGL 사격과 전체 T022/T023 완료를 의미하지 않는다. 장면·피격·입력 통합 후 게임에서 별도로 확인한다.
