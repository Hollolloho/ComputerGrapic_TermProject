# STORY

게임 규칙·기본 사건·추리 콘텐츠의 기준 문서다. 제작 범위와 일정은 [DEVELOPMENT](DEVELOPMENT.md), 실행할 작은 단계는 [TASKS](TASKS.md)에 둔다.

## 1 기본 사건과 플레이 목표

중세 유럽풍 마을의 비리를 조사하던 조사관이 여관에서 살해된다. 플레이어는 그날의 방문자들을 조사하고, 현장 물건에 남은 과거의 흔적 ‘잔향’을 통해 현재와 과거의 차이를 발견한다. 증언·기록·관찰을 대조해 범인과 범행 경위를 밝힌다.

감정적인 장편 서사보다 직접 관찰하고 판단을 수정하는 재미를 우선한다. 처음에는 수상했던 사람의 거짓말이 살인과 다른 이유에서 비롯됐음을 알게 되고, 남은 근거로 범인을 좁히는 경험을 만든다. 사건은 과거 화재·가족사·귀족 거래를 먼저 이해하지 않아도 설명되어야 한다.

### 사건의 실제 순서

1. 에드윈이 마을 감사를 마치고 돌아갈 준비를 한다.
2. 범행 전 에드윈은 두통으로 레온을 여관방에 부른다. 레온은 에드윈을 진찰하고 처방용 유리 약병을 방에 두고 간다.
3. 카일은 에드윈의 여관방에 자기 장부가 나와 있는 것을 발견하고 되찾으려 한다.
4. 에드윈이 장부를 가져가는 카일을 보고 제지한다. 두 사람이 다투는 중 카일은 방에 있던 금속 촛대를 집어 들어 에드윈을 살해한다.
5. 카일은 다툼의 흔적을 감추고 레온의 약병을 시신 곁에 두어 범행에 쓰인 물건처럼 보이게 한다. 장부와 촛대는 가져간다.
6. 다음 날 아침, 여관 주인 마리가 에드윈의 출발 준비를 확인하러 방에 갔다가 시신을 발견한다.

장부에 담긴 비리, 레온의 방문 시각, 현장에 남은 흔적은 첫 주에 정한다. 플레이어가 살해 도구를 추리할 때 레온의 약병과 촛대를 비롯한 후보를 비교한다. 각 후보를 의심할 이유와 촛대로 좁힐 근거를 증거 설계에서 정한다.

## 2 인물

이름은 작업용이며 이전 초안의 범행·가족관계·비밀을 승계하지 않는다.

| 인물 | 최소 역할 | 정할 내용 |
|---|---|---|
| 플레이어 | 외지 조사자 | 도착 안내와 현재 목표 |
| 에드윈 | 비리를 조사하다 살해된 조사관 | 조사 내용·확보한 증거·범행 전 행동 |
| 마리 | 여관 주인. 아침에 에드윈의 출발 준비를 확인하러 갔다가 시신을 발견한다 | 출입·발견 당시 방의 상태에 관해 아는 범위와 증언 |
| 레온 | 마을 의사. 두통으로 부른 에드윈을 진찰하고 처방용 유리 약병을 두고 간다 | 방문 시각·목격 주장·숨기는 행동 |
| 카일 | 마을 경비대장. 장부를 되찾으려다 에드윈을 살해한 범인 | 장부의 비리·현장 접근권·구체적인 행동과 증언 |

대화 인물은 최대 세 명이다. 직업만으로 사망 시각·사인이나 범인 여부를 확정하지 않는다. 모든 사람에게 살인 시도를 부여하지 않으며, 인물별로 실제 행동·아는 사실·주장·의심 단서·해명 또는 유죄 근거를 나누어 쓴다.

## 3 잔향 규칙

이번 사건의 매개체는 여관방에서 오래 쓰던 낡은 잉크통이다. 밑면에 여관 표식이 있다.

- 현장 물건에 남은 실제 과거 한순간을 정지된 3D 공간으로 관찰한다. 반복해도 같은 장면이다.
- 공간 안에서 걸으며 위치·가림·거리·물건 배치를 살필 수 있다. 물건 이동·인물과 대화·과거 변경은 할 수 없다.
- 현재 현장이 바뀌어도 보존된 장면은 달라지지 않는다. 원하는 사람이나 사건을 합성하지 않는다.
- 장면은 사실이지만 정확한 시각·의도·사인까지 자동으로 설명하지 않는다. 장소·시간은 기록과 표식으로 확인한다.
- 잉크통에 남은 순간과 공간 범위는 기본 사건과 함께 정한다. 생성 원리·기억 손실·촬영·덮어쓰기·거래 시장은 이번 게임의 전제로 넣지 않는다.

잔향은 살인 장면을 통째로 보여주는 정답 영상이 아니라 증언과 현장 조작을 검증하는 공간이다. 정지 인물의 자세만으로 생존을 판정하지 않는다.

## 4 플레이 흐름

| 단계 | 플레이어 행동과 얻는 정보 |
|---|---|
| 시작 | 사건·목표·조작을 확인한다. 긴 과거 설명은 생략한다. |
| 현재 조사 | 물건·사람을 조사하고 현장 상태·증언을 수첩에 기록한다. |
| 상세보기 | 낡은 잉크통을 공전·확대하여 밑면의 여관 표식을 확인한다. |
| 잔향 관찰 | 같은 공간의 과거를 돌아다니며 배치와 시야를 비교한다. |
| 중간 판단 | 주장과 근거를 선택해 특정 증언의 모순을 반박한다. |
| 후속 조사 | 수정 진술과 다른 근거를 대조해 실제 범행을 좁힌다. |
| 최종 판단 | 범인과 필요한 근거를 제출한다. 오답·부족은 재조사로 돌아간다. |
| 결과 | 수집한 사실로 해설하고 재시작 또는 종료한다. |

## 5 대표 퍼즐과 증거

현재/과거에 같은 방·복도·관찰 표식을 둔다. 복도 표시 지점에서 열린 출입구 너머 책상 위 봉투를 바라본다. 현재 책장은 옆에 있지만 과거에는 봉투로 향하는 시야를 막는다.

**테스트 증언:** “그날 저녁 복도의 표시 지점에서 책상 위 봉투를 직접 봤습니다.”

**작업 기록:** “책장은 그날 낮 설치했고 다음 날 아침 옮겼다. 그 사이 위치를 바꾸지 않았다.” 실제 적용 전에 사건 날짜·진술자·기록 출처를 정한다.

| ID | 기록되는 정보 | 획득 방법 |
|---|---|---|
| EV_TESTIMONY | 인물이 해당 위치에서 봉투를 직접 봤다고 주장했다 | 대화 |
| EV_SHARD | 잉크통 밑면의 여관 표식과 기록이 잔향 속 장면을 해당 방에 연결한다 | 공전·확대 상세보기 |
| EV_WORKLOG | 책장 설치·이동 시각과 중간 배치 유지 | 기록물 조사 |
| EV_OCCLUSION | 과거 표시 위치에서 책장이 봉투를 가린다 | 잔향에서 직접 관찰 |

EV_SHARD는 잉크통 표식 카드의 ID다. 안내 대사는 표식과 기록을 대조하도록 유도한다.

| 선택 | 판정 |
|---|---|
| A 해당 위치·시각에서 봉투를 직접 볼 수 있었다 | 오답 |
| B 직접 봤다는 주장은 관찰과 배치 기록에 맞지 않는다 | 정답 |
| C 그 진술자가 조사관을 죽였다 | 근거 부족 |

B에 EV_TESTIMONY·EV_WORKLOG·EV_OCCLUSION을 선택하고 EV_SHARD의 장소 확인까지 얻으면 중간 판단을 완료한다. 선택 순서는 무관하다. 다른 위치에서 봤거나 전해 들었을 가능성이 있으므로 이 결과는 해당 목격 주장만 반박한다. 유죄 판단에는 별도의 범행 근거가 필요하다.

실제 배치에서 작은 좌우 이동·눈높이·화면비·책장 틈을 검증한다. 점프·벽 통과·상세보기 카메라로 가림을 우회하지 못하게 한다. 자동 ‘거짓말’ 자막 대신 사실인 관찰만 기록한다.

## 6 첫 주에 정할 사건

[TASKS의 S001~S008](TASKS.md#case)에서 다음을 순서대로 작성한다.

1. 범인·비리·동기를 한 문단으로 설명한다.
2. 방문·생존 확인·범행·현장 조작·발견의 순서와 위치를 정한다.
3. 잔향 매개체·보존 순간·범위와 장소·시간을 확인할 근거를 정한다.
4. 중간 퍼즐의 네 카드를 포함해 총 6~8개 이내로 유죄 근거를 구성한다.
5. 다른 인물의 의심·해명, 조사 후 대사, 최종 판단·오답·해설을 쓴다.
6. 진상을 가린 채 동료가 단서만으로 해답을 설명하고 다른 범인 가능성을 검토한다.

시간표는 **순서 / 실제 행동·위치 / 인물의 주장 / 확인 근거** 네 항목으로 작성한다. 증거는 **ID / 화면 문구 / 획득 조건 / 입증하는 것 / 입증하지 못하는 것 / 사용할 판단**으로 작성한다.

기록은 작성 내용만 보여주며 항상 진실인 것으로 가정하지 않는다. 범행 방법·접근·행동을 인물과 연결하고 다른 해답을 배제해야 한다. 공개 저지를 동기로 쓰면 이미 전달된 사본·외부 증언과 살인으로 막을 수 있는 범위를 구분한다. 필수 근거를 결말의 자백이나 추가 스토리에 숨기지 않는다.
