# TASKS

실제 완료 체크는 이 파일 한 곳에서 관리한다. A=홍준호, B=윤형균. 선행 ID가 완료된 작은 작업부터 진행하고 변경 파일·실행 결과를 기록한다. 문서 수정으로 체크하지 않는다.

첫 주에는 S 사건 기획·A 에셋·B 실행 기반을 병행하며 G001~G009도 필요한 순서에 맞춰 진행한다. 표의 배치 순서보다 각 행의 선행 조건을 따른다. 같은 형상 제작과 배치가 이미 끝났으면 다시 만들지 말고 해당 단계의 검증을 수행한다.
