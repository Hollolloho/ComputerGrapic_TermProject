# 다음에 결정할 이야기 항목

현재 안의 미확정 부분을 한곳에서 관리한다. 다른 문서에서 답을 추측해 채우지 않는다.

| 순서 | 결정할 질문 | 완료 산출물 |
|---|---|---|
| 1 | 다니엘은 왜 불을 질렀고 왜 함께 죽었나 | 발화 전후 실제 순서 |
| 2 | 구조 요청·치료 지연·거래 은폐는 어떻게 이어졌나 | 7년 전 시간표와 인물별 지식 |
| 3 | 에드윈은 왜 이제 공개하려 했나 | 공개의 계기와 발표할 내용 |
| 4 | 초대장과 카일의 협박 편지는 같은 것인가 | 편지별 발신·수신·전달 시각 |
| 5 | 마리는 약을 어떻게 구했고 왜 죽였다고 믿나 | 의도·관찰·오해의 연결 |
| 6 | 노아는 투여를 어떻게 알고 이용했나 | 정보 획득과 의심 유도 행동 |
| 7 | 노아의 실제 살해 방법과 독립 증거는 무엇인가 | 사인·현장·기회·배제 근거 |
| 8 | 9시 약속 전후 각 인물은 어디 있었나 | 현재 사건의 실제 시간표 |
| 9 | 잔향은 어느 순간과 범위를 보존하나 | 장면별 사실·주장·입증·한계 |
| 10 | 첫 제출본에 어떤 조사 하나를 넣을까 | 제한된 NPC·카드·정답의 확정본 |

현재 초안에서 정한 것은 인물의 역할과 반전이다. 의학적 작용·감식 방법·세부 범행을 이미 검증된 설정으로 제시하지 않는다. 제작자가 확정한 정보와 플레이어가 추론할 정보를 따로 기록한다.
