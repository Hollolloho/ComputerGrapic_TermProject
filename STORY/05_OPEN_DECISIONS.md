# 추가로 결정하고 작성할 세부 기획

갱신일: 2026-11-08. 사용자가 요청한 [4주 제출본 기준](06_FOUR_WEEK_SCOPE.md)의 상세 작성 목록이다. 전체 목록을 한 번에 답받지 않고 한 항목씩 정한다. 이 목록 작성으로 미정인 설정을 채택하거나 제품 작업을 완료 처리하지 않는다.

## 1. 이번에 완성할 기획의 형태

작은 여관 조사 구역, 대화 인물 최대 3명, 잔향 1개, 단서 6~8개 이내로 **에드윈 살인을 카일의 범행으로 입증하는 사건**을 설계한다. 숫자를 채우는 것보다 적은 단서로도 공정한 결론이 나오는 것이 우선이다.

이미 정한 뼈대는 유지한다: 카일의 불법 잔향 거래·과거 방화·현재 살인, 마리의 재조사 요청, 에드윈의 피해자 역할, 루카스의 구조 직후 생존과 레온의 치료 지연. 추가할 내용은 이 사실들이 어떻게 연결되고 플레이어에게 어떻게 드러나는지다.

첫 구매 귀족의 동기는 **이 마을에서 즐거워하던 아이의 표정을 다시 보고 싶다**로 채택했다. 귀족 가족은 **휴양차 마을에 머물렀다**. 장면은 **여관 정원에서 놀던 아이가 작은 꽃을 부모에게 내밀며 환하게 웃는 순간**이다. 기록 조건과 거래 경로는 후속 결정이다.

## 2. 직접 결정해야 할 내용

아래 순서는 권장 논의 순서다. 1~3의 배경을 짧게 정한 뒤 4~7의 범행과 입증에 시간을 집중한다. 막히는 배경 세부가 현재 살인의 해답에 영향을 주지 않으면 미정으로 남기고 진행한다.

| 순서 | 결정할 항목 | 구체적으로 채울 내용 | 완료 기준 |
|---|---|---|---|
| 1 | 귀족의 잔향 기록과 거래 | 구매 동기·휴양차 방문·정원에서 꽃을 내미는 장면은 채택됨. 그 순간이 기록된 조건, 카일이 실제 잔향을 확보·확인하고 구매자와 연결하는 경로 | 구매자 한 명의 사연과 거래 과정을 한 단락으로 설명 |
| 2 | 이번 사건에 필요한 잔향 규칙 | 언제·어디까지 기록되는가, 조각을 누가 어디서 확보했는가, 진입·재생 조건, 거래·반출 금지의 이유 | 기록·관찰·이동·재생·제한을 짧게 적고 사건의 조각에도 동일하게 적용 |
| 3 | 재조사와 현재 범행 동기 | 마리의 새 단서와 출처, 에드윈이 확인한 것, 현장·중앙에 있는 자료, 카일이 알아낸 범위와 공개를 막을 수 있다고 판단한 이유 | ‘왜 지금 살인했는가’를 남은 자료·보고 상태와 모순 없이 설명 |
| 4 | 현재 살인의 실제 과정 | 장소·수단·접근 경로, 피해자의 마지막 확실한 생존과 발견, 범행 후 카일이 한 행동, 남은 흔적 | 제작자용 범행 요약 한 단락. 단순한 원한·방문 사실만으로 유죄가 되지 않음 |
| 5 | 인물별 시간표 | 에드윈·마리·레온·카일의 실제 위치와 행동, 서로 본 것, 각자 주장, 잔향 기록 시점 | 생존 확인부터 발견까지 핵심 사건 5~7개 정도를 표로 연결. 시간의 근거도 표시 |
| 6 | 잔향 장면과 방 배치 | 어떤 한 순간인가, 보존 범위, 문·창·책상·책장·사람·조사 물체 위치, 현재와 다른 점, 이동해야 확인되는 사실 | 현재/과거 평면도 각 1장과 ‘이 장면으로 알 수 있는 사실’ 한 문장 |
| 7 | 증언과 증거의 연결 | 마리·레온·카일이 실제로 아는 것과 하는 말, 거짓말·착오 여부, 이를 검증할 단서, 다른 범인 가설을 배제하는 이유 | 각 판단에 플레이어가 얻을 근거가 있고 카일에게만 현재 살인의 해답이 성립 |
| 8 | 도입·진행·결말 | 외지 조사관인 플레이어가 도착한 이유, 조사 접근권과 인물들이 남아 있는 이유, 첫 목표, 중간 판단, 최종 제출 조건, 마리와 카일의 마지막 반응 | 처음 접한 사람이 목표를 알고 시작해 근거를 제출하고 결과·재시작까지 이해 |

4~7은 함께 대조하며 수정한다. 수법만 먼저 고정한 뒤 잔향에 억지로 맞추지 않는다. 잔향 하나와 작은 공간으로 입증할 수 없으면 수법·시간표를 단순하게 한다.

## 3. 결정 후 실제로 작성할 자료

아래 분량은 초안 작성의 상한 또는 가이드이며 추가 기능 요구가 아니다. 사용자는 사건의 방향과 선택을 정하고, 이 채팅에서 문장·표·카드 초안을 함께 구체화한다. 사건 진상과 플레이어가 아는 정보를 분리한다.

| 자료 | 권장 분량 | 꼭 들어갈 내용 |
|---|---|---|
| 제작자용 진상 | 1쪽 이내 | 재조사 계기 → 카일의 판단 → 범행 → 은폐 → 발견. 아직 공개되지 않는 사실도 구분 |
| 사건 시간표 | 표 1개 | 시점, 실제 행동·위치, 인물의 주장, 그 시점을 뒷받침할 증거 |
| 현재/잔향 배치도 | 간단한 그림 각 1장 | 출입구·벽·가림 물체·인물·조사 지점·플레이어 관찰 위치. 외관 일러스트보다 가림 관계를 먼저 확정 |
| 인물별 진술표 | 최대 3명 | 실제 지식·주장·거짓말/착오 여부·검증 근거·판단 후 반응. 모든 인물에게 비밀을 추가하지 않음 |
| 증거 카드 원고 | 6~8개 이내 | 이름·획득 위치/대상·필요 조건·화면 설명·입증 사실·입증하지 못하는 것·사용할 판단 |
| 대사·문서 원고 | 기본 대화 각 1세트와 필요한 반응만 | 마리의 의뢰, 레온의 진술, 카일의 설명, 선택한 귀족 사연, 조사·거래 기록의 실제 본문. 긴 대화 분기 없음 |
| 추리 문항·정답 근거 | 중간 1개·최종 1개 | 질문, 선택지, 필요한 근거, 정답 설명, 오답/근거 부족 시 안내와 복귀 위치 |
| 도입·결말 원고 | 각각 짧은 화면 1개 분량 | 지금 조사할 목표, 실제로 입증한 결론, 마리의 반응, 남은 과거 의문, 종료/재시작 안내 |

단서가 모자라면 외형적인 카드 개수부터 늘리지 않는다. 같은 단서가 여러 판단에 쓰일 수 있지만, 같은 출처를 다시 말한 것을 독립된 뒷받침으로 세지 않는다. 추가 잔향이나 결말 자백에 필수 근거를 숨기지 않는다.

### 복사해서 채울 단서 양식

```text
단서 이름:
획득 장소·대상·조건:
플레이어에게 보이는 설명:
직접 확인되는 사실:
이것만으로 알 수 없는 것:
함께 대조할 증언·다른 단서:
사용할 판단과 그 이유:
```

### 복사해서 채울 시간표 양식

| 시점·순서 | 실제 사건·위치 | 인물의 주장 | 플레이어가 확인할 근거 |
|---|---|---|---|
| 생존 확인 | 작성 전 | 작성 전 | 작성 전 |
| 사건 전후 핵심 행동 | 필요한 만큼 행 추가 | 작성 전 | 작성 전 |
| 사망 발견 | 작성 전 | 작성 전 | 작성 전 |

## 4. 지금은 짧게 정하거나 뒤로 미룰 내용

| 항목 | 제출본에 필요한 깊이 | 나중에 정할 부분 |
|---|---|---|
| 귀족과 마을 방문 | 휴양 중 즐거워하던 아이의 표정을 다시 보고 싶은 동기, 실제 기록이 남은 이유 | 귀족 가문사·여러 구매자·저택·마을 전체 역사 |
| 거래와 창고 화재 | 없애려던 기록과 그중 남은 단서, 재조사와의 연결 | 운송망 전체·상세 방화 재연·별도 창고 탐색 |
| 루카스의 창고 방문·치료 | 게임에서 언급하거나 현재 해답에 쓰는 부분만 모순 없게 정함 | 방문의 상세 비밀·치료 지연의 구체적 이유와 인과를 조사하는 별도 과제 |
| 7년 전 수사와 은폐 | 당시 부족했던 근거와 이번에 새로 생긴 근거를 구분 | 관련자 전원의 과거 행적·매수·기록 조작의 세부 |
| 레온의 살인 시도 | 4주 제출본의 전제로 사용하지 않음 | 채택 여부, 시도 수단, 잘못된 확신, 실제 사망과의 구분 |
| 노아·마리의 추가 비밀 | 기존 직업과 역할을 유지하고 미채택 비밀을 대사에 넣지 않음 | 매수·문서 교체·루카스를 보낸 사정의 채택과 입증 |
| 잔향의 확장 능력 | 보존된 장면의 관찰에 필요한 규칙만 사용 | 외부 새 기록·덮어쓰기·수명 전체 체계·기억 손실의 게임 규칙 |

‘뒤로 미룸’은 기존 설정을 삭제한다는 뜻이 아니다. 기본 결말에서 주장할 사실이면 근거를 이번 제출본 안에 포함해야 한다. 설명하지 않은 치료 지연을 직접 사망 원인으로 단정하지 않고, 자료를 태웠다는 사실만으로 현재 살인을 확정하지 않는다.

## 5. 작성 완료 판단

- 도입에서 플레이어의 목표와 조사 가능한 범위를 알 수 있다.
- 실제 시간표·인물 진술·단서 위치·과거 배치가 서로 일치한다.
- 잔향에서 보이는 정지 자세만으로 생존·정확한 시각·의도·사인을 확정하지 않는다. 필요한 시간·상태는 다른 근거와 연결한다.
- 레온의 진술을 반박하는 데 성공했다고 카일의 살인이 자동으로 입증되지는 않는다. 카일의 실제 범행을 연결하는 근거가 별도로 있다.
- 마리·레온 또는 다른 접근 가능한 인물에게 같은 범행 해답이 성립하지 않는 이유를 설명할 수 있다.
- 필수 단서를 정상적인 플레이로 모두 얻을 수 있고, 중간 판단 때문에 최종 단서가 영구히 막히지 않는다.
- 결말은 플레이어가 이미 입증한 사실을 정리한다. 새 능력·새 증거·자백으로 빈 추론을 메우지 않는다.
- 처음 읽는 사람이 ‘왜 카일인가’를 근거와 함께 설명할 수 있다.

## 6. 다음 논의와 기록 방식

구매 동기·휴양차 방문·정원에서 꽃을 내미는 장면은 확정했다. 다음은 **그 순간이 어떻게 잔향에 기록되었는가**를 정한다. 그 뒤 카일의 확보·확인·거래 경로를 한 항목씩 정한다. 카일이 기록을 먼저 확인한 뒤 구매자에게 접근하는 방식은 아직 제안이다.

그 뒤 이번 사건에 필요한 잔향 규칙 → 재조사와 공개 저지 동기 → 범행·시간표·증거를 순서대로 정한다. 선택된 내용만 관련 STORY 문서와 AI_HANDOFF에 반영한다. 구현 완료 체크와 실행 확인은 개발 채팅에서 관리한다.
