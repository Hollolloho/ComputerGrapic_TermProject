# 7년 전 화재

## 채택된 사실

- 장소: 구호 물자 창고. 불법 거래도 이루어졌다.
- 피해자: 루카스와 다니엘. 루카스는 구조 직후까지 생존했다.
- 실제 발화: 다니엘의 방화.
- 공식 설명: 시설의 등불·난로 관리 사고. '노후 전기 설비'는 중세 배경에 맞춰 교체한다.
- 레온: 루카스의 치료를 지연했고 의료 기록 수정을 요청했다.
- 카일: 에드윈에게 돈을 받고 거래 기록을 없애고 사고 조사로 꾸몄다. 방화범의 정체는 몰랐다.
- 에드윈: 구조 요청을 포함한 관련 기록 은폐에 관여했다.
- 마리: 구조 요청 기록 조작을 최근 알았다.
- 노아: 공개 예정일에 아버지의 방화를 알았다.

## 실제 순서에서 정할 빈칸

| 순서 | 고정된 부분 | 아직 정할 부분 |
|---|---|---|
| 발화 전 | 창고에서 거래가 있었다 | 거래 품목·관련자·다니엘이 개입한 이유 |
| 발화 | 다니엘이 불을 질렀다 | 의도한 결과와 본인 사망 경위 |
| 구조 | 루카스가 살아서 구조되었다 | 요청 시각, 구조 경로, 기록의 원문 |
| 치료 | 레온이 치료를 지연했다 | 지연 이유, 목격, 실제 영향 |
| 은폐 | 구조·의료·거래 기록이 고쳐지거나 없어졌다 | 누가 먼저 요구했고 누가 무엇까지 알았는지 |
| 공식 종결 | 사고로 발표되었다 | 남은 원본과 진실을 다시 찾을 경로 |

이전 안의 '전염병 때문에 지원을 기다리다 아들이 죽었다', '접수 기한을 늦게 고쳤다'는 이야기를 별도의 사실로 섞지 않는다. 현재 과거 사건은 화재다.

각 인물의 책임은 기록과 독립된 자료로 확인한다. 카일이 부패했다는 사실만으로 방화를 알았다고 단정하지 않고, 치료 지연이 있었다는 사실만으로 구체적인 사망 인과를 자동 확정하지 않는다.
