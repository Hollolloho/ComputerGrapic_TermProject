## 상태 구분

- **채택:** 사용자가 선택한 설정과 최신 이야기로 진행하기로 한 방향.
- **제안:** 검토 가능한 연결 방식. 사용자가 선택하기 전에는 사건의 사실로 쓰지 않는다.
- **미정:** 구체적인 범행·단서·시간표 등 후속 설계가 필요한 내용.

첫 구매 귀족의 동기·가족의 휴양차 방문·여관 정원에서 꽃을 내밀며 웃는 아이의 장면은 채택했다. 기록 조건과 거래 경로는 미정이다. 레온의 살인 시도, 노아의 매수·문서 조작, 마리의 비밀은 아직 제안이다. 사건의 상세 방법과 독립 증거가 정해지기 전에는 완성된 유일해 퍼즐이라고 보지 않는다.

중세 유럽풍 배경을 유지하고 직업별 권한과 관찰 가능한 사실을 구분한다. 현대적인 감식 능력을 자동으로 부여하지 않는다.

[AI_HANDOFF](../AI_HANDOFF.md)는 현재 상태를 요약한다. [DEVELOPMENT](../DEVELOPMENT/README.md)에서는 실제 제작할 분량을 따로 정한다.
