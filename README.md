# 내일도 와줄 거지 — 프로젝트 문서

갱신일: 2026-11-08. 작업 제목이며 최종 제목은 사건 설계 후 검토합니다.

카일이 금지된 잔향 조각 거래를 운영하고, 거래 기록을 없애려 일으킨 7년 전 화재와 재조사 중인 에드윈의 살인을 감추는 3D 1인칭 추리 게임입니다. 마리는 아들 루카스의 죽음을 조사해 에드윈을 다시 부른 의뢰인이자 조력자입니다.

최신 이야기와 문서의 상태 구분은 다음 순서로 읽습니다.

- [AI_HANDOFF](AI_HANDOFF.md): 현재 기준, 작업 범위, 다음에 결정할 항목.
- [STORY](STORY/README.md): 이야기·인물·사건·잔향 규칙과 미정 사항.
- [DEVELOPMENT](DEVELOPMENT/README.md): 시제품 범위·카메라·구현 작업 목록.
- [기획 할 일 공유본](기획_할일_공유용.md): 팀원에게 전달할 확정 설정·남은 결정·작성 자료·일정 체크리스트.

첫 구매 귀족은 가족과 휴양차 이 마을에 머물렀으며, 여관 정원에서 작은 꽃을 부모에게 내밀며 환하게 웃던 아이의 모습을 다시 보고 싶어 잔향을 삽니다. 잔향의 기록 조건·거래 경로, 외부 기록 기능은 미정이며 레온의 살인 시도, 노아의 거래 가담, 마리의 비밀은 아직 제안입니다. 이야기의 채택과 구체적인 범행·증거 설계의 완료를 구분합니다.

OpenGL 카메라 확대·이동·자전·공전·부모 관계는 모두 프로젝트 필수 조건입니다. 기본 시제품은 방 하나·NPC 두 명·잔향 하나·증거 네 개의 조사 과제를 계획합니다. 문서 수정은 구현 완료를 뜻하지 않습니다.
